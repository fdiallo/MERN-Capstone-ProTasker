

Pro-Tasker is a modern, collaborative project management tool that is intuitive for single users but powerful enough for small teams. The application is be built from the ground up using the MERN stack, showcasing a secure, robust, and feature-rich backend API, a dynamic and responsive React frontend, and a seamless deployment pipeline.

Technologies Used:

Fron End:
    React
    

Back End:
    Node
    Express
    Mongo DB - Mongoose
